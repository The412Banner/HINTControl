Fifth test build of **Hint Plus**. First fix from a real gateway (Arcadyan TMO-G5AR, firmware 1.00.06). Update under **More → Updates**.

> **Test build.** Status and live signal are now confirmed on a real TMO-G5AR. Devices, Wi-Fi settings and reboot on real hardware are still being checked.

## Fixed
- **Devices on G5AR / G5SE gateways:** Wi-Fi devices now show. These gateways list Wi-Fi clients in one `wifi` group instead of per band, which HINT Control never read, so only wired devices appeared. Found by **cmarker84** and confirmed on a G5SE by **fitzmorrispr** in [HINT Control issue #123](https://github.com/zacharee/HINTControl/issues/123).

## Checked on a real gateway (TMO-G5AR, firmware 1.00.06)
Gateway found automatically at 192.168.12.1, login, status, 5G-only signal (no LTE) and live history.

## Install
`HintPlus-v1.0.0-pre5-<build>.apk`, signed with the public AOSP test key (v1 + v2 + v3). Android 8.0+. Check the download against the `.sha256` file.
