**Hint Plus 1.0.1** fixes problems that users reported to the original [HINT Control](https://github.com/zacharee/HINTControl) by Zachary Wander. Update under **More → Updates**.

## Fixed and added
- **Slow gateways no longer show "not found"** ([HINT Control #122](https://github.com/zacharee/HINTControl/issues/122)). If the gateway doesn't answer within 5 seconds, Hint Plus keeps looking for up to 20 seconds before giving up.
- **VPN warning** ([#84](https://github.com/zacharee/HINTControl/issues/84)). When the gateway can't be reached and a VPN is on, the message says so; many VPNs send local traffic away from the gateway.
- **Correct password refused** ([#2](https://github.com/zacharee/HINTControl/issues/2), [#129](https://github.com/zacharee/HINTControl/issues/129), [#134](https://github.com/zacharee/HINTControl/issues/134)). Some gateways stop accepting the right password until they restart; the message now says to restart the gateway.
- **Band changes on the history chart** ([#102](https://github.com/zacharee/HINTControl/issues/102)). Each band change is marked on the chart with the new band.
- **Fixed chart scale** ([#127](https://github.com/zacharee/HINTControl/issues/127)). A "Fixed scale" switch keeps the chart's range steady instead of fitting the data.
- **Tower names** ([#24](https://github.com/zacharee/HINTControl/issues/24)). Give a cell tower your own name on **Signal → Cell**; it shows there and on Home.

## Install
`HintPlus-v1.0.1-<build>.apk`, signed with the public AOSP test key (v1 + v2 + v3). Android 8.0+. Check the download against the `.sha256` file.
