Third test build of **Banners HINT Control**. Small fixes found while testing the in-app update from pre1 to pre2 on a device. If you have pre2, the app offers this update under **More → Updates**.

> **Test build.** Still **not tested on a real gateway**. Please report what works and what doesn't. The demo gateway shows every screen without hardware.

## Fixed
- Widget and Quick Settings tile: when the gateway doesn't answer because your phone isn't on its network (away from home), they now say **Not on gateway network** instead of "Gateway offline"
- Updates: after you allow "install unknown apps" in Android's settings, the **Install** button works straight away (before, you had to leave and reopen the screen)
- Release notes: quoted lines display properly
- The downloaded update file is removed after the update (frees about 3 MB)
- Bottom bar: the tab stays highlighted while you're on one of its pages (Updates, Event log, …)
- The update badge stays on **More** until a downloaded update is installed

## Checked on a device (demo gateway)
In-app update from v1.0.0-pre1 to v1.0.0-pre2: found the release, downloaded it, checked the SHA-256, Android's update prompt, installed; settings and history kept.

## Install
`HINTControl-v1.0.0-pre3-<build>.apk`, signed with the public AOSP test key (v1 + v2 + v3). Android 8.0+. Check the download against the `.sha256` file.
