**Hint Plus 1.1.2** tells you when a gateway quietly ignores a Wi-Fi change, and when its firmware updates. Update under **More → Updates**.

## New
- **"Did it stick?" check for Wi-Fi changes.** After saving, Hint Plus reads the settings back and compares them with what it sent. If the gateway accepted a change but kept its own value (for example a channel that goes back to Auto), you now see *Not all changes stuck* with the list, instead of a plain "Saved". The event log notes it too. Reported on Reddit by Hot-Bat-5813.
- **Firmware updates are tracked.** Gateways get firmware from T-Mobile on their own; Hint Plus now notices when the version changes, adds "Firmware updated (old → new)" to the event log and sends a notification. You can turn the notification off under **More → Alerts**.

- **Samsung tip.** On Samsung phones, if Android blocks an update, Hint Plus now points to Auto Blocker (Settings → Security and privacy → Auto Blocker), which blocks installs from outside the Play Store. Tip from Hot-Bat-5813.

## Fixed
- The demo gateway no longer logs a false "Gateway restarted" every time the app is restarted or updated.

## Install
`HintPlus-v1.1.2-<build>.apk`, signed with the public AOSP test key (v1 + v2 + v3). Android 8.0+. Check the download against the `.sha256` file.
Samsung phones: turn off Auto Blocker before installing (Settings → Security and privacy → Auto Blocker).
