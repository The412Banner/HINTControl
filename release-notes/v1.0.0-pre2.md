Second test build of **Banners HINT Control**. Fixes from the first on-device test (Android 14 handheld, demo gateway). If you have v1.0.0-pre1 installed, the app offers this update under **More → Updates**.

> **Test build.** Still **not tested on a real gateway**. Please report what works and what doesn't. The demo gateway shows every screen without hardware.

## Fixed
- Wi-Fi: the network editor is now a full-screen page; before, the keyboard ended up behind it and its top rows were hidden
- Notifications: the app now asks once for notification permission after setup (Android 13+); without it, alerts and update notices stayed silent
- History chart: the cursor line, dots and time readout now point at the same reading
- Devices: clear button in the search box
- Gateway details: hidden SIM numbers line up with the other values
- Cell details: registration status capitalised like on Home
- Android's predictive back gesture is enabled
- Demo gateway: 5G cell ID matches its gNB/cell, valid gateway MAC

## Checked on a device (demo gateway)
Setup and gateway search, Home, live signal, placement tone, history, cell details, devices (search, rename), Wi-Fi edit/review/save incl. the 6 GHz fix, reboot with downtime, event log, update check, a scheduled reboot firing with the app in the background, landscape layout.

## Install
`HINTControl-v1.0.0-pre2-<build>.apk`, signed with the public AOSP test key (v1 + v2 + v3). Android 8.0+. Check the download against the `.sha256` file.
