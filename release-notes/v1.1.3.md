**Hint Plus 1.1.3** fixes the "NetworkOnMainThreadException" error on the Devices screen. Update under **More → Updates**.

## Fixed
- **Devices sometimes showed "Something went wrong – NetworkOnMainThreadException"** on first open and only worked after switching tabs. Hint Plus finished reading the gateway's reply on the main thread, which Android blocks; the device list is the longest reply, so it showed up there most. Replies are now read completely in the background. This could affect other screens too, so all of them get the fix. Reported on Reddit by f1vefour (Pixel 10, Android 17, TMO-G5AR).

## Install
`HintPlus-v1.1.3-<build>.apk`, signed with the public AOSP test key (v1 + v2 + v3). Android 8.0+. Check the download against the `.sha256` file.
Samsung phones: turn off Auto Blocker before installing (Settings → Security and privacy → Auto Blocker).
