Fourth test build. The app is now called **Hint Plus** (formerly "Banners HINT Control"). If you have an earlier test build, it updates in place under **More → Updates** — your gateways, history and settings stay.

> **Test build.** Still **not tested on a real gateway**. Please report what works and what doesn't. The demo gateway shows every screen without hardware.

## Changed
- New name **Hint Plus** on the launcher, in About and in shared reports
- Download file is now `HintPlus-v<version>-<build>.apk`

Nothing else changed since v1.0.0-pre3. The app ID stays `com.banner.hintcontrol`, so it installs over earlier test builds.

## Checked on a device (demo gateway)
In-app updates from v1.0.0-pre1 → pre2 → pre3 on an Android 14 handheld: found the release, downloaded it, checked the SHA-256, installed it; settings and history kept.

## Install
`HintPlus-v1.0.0-pre4-<build>.apk`, signed with the public AOSP test key (v1 + v2 + v3). Android 8.0+. Check the download against the `.sha256` file.
