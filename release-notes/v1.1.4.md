**Hint Plus 1.1.4** stops the refresh spinner from popping up on its own. Update under **More → Updates**.

## Fixed
- **The refresh spinner no longer appears every few seconds on Home.** Each automatic update (every 5 s by default) showed the pull-to-refresh spinner, which slid in and out and made the screen hitch. Automatic updates now change the numbers quietly; the spinner only shows when you pull down or tap refresh. Reported on Reddit by f1vefour.

## Install
`HintPlus-v1.1.4-<build>.apk`, signed with the public AOSP test key (v1 + v2 + v3). Android 8.0+. Check the download against the `.sha256` file.
Samsung phones: turn off Auto Blocker before installing (Settings → Security and privacy → Auto Blocker).
