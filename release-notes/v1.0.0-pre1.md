First test build of **Banners HINT Control** — an Android-only rebuild of [HINT Control](https://github.com/zacharee/HINTControl) by Zachary Wander (MIT) in Jetpack Compose, with new tools for T-Mobile Home Internet gateways.

> **Test build.** The gateway code is ported from HINT Control and unit-tested against recorded responses, but this build has **not been tested on a real gateway** yet. Try it, and please report what works and what doesn't. A built-in demo gateway shows every screen without hardware.

## Highlights
- **Home**: signal score, 5G/LTE gauges (RSRP, SINR, RSRQ, RSSI), bands with frequency, uptime, devices, 30-minute trend
- **Placement mode**: one reading per second with a tone and buzz that rise with the signal, and the best spot remembered
- **Signal history** up to 30 days with drag-to-read charts, band changes and CSV export
- **Cell details**: PCI, EARFCN/NR-ARFCN, CQI, eNB/gNB, TAC, supported bands, gateway location
- **Devices**: search, filters, sorting, your own names, new-device badge, private-MAC note
- **Wi-Fi**: edit networks (including hide/show the name), share as QR code, radios, channel, width, power, band steering; review every change with warnings before saving
- **Reboot** with progress and downtime, **scheduled reboot**, change admin login (TMI gateways)
- **Alerts**: offline, restart, weak signal, new device; event log
- **Widget**, **Quick Settings tile**, launcher shortcuts, automation broadcasts for Tasker/MacroDroid
- **In-app updates** from this repository's releases (SHA-256 checked); test builds can be turned on or off
- Several gateways, Material You, dark and pure-black themes, layouts for phones, tablets and landscape handhelds

## Fixed compared with HINT Control 1.17.3
- Editing the 6 GHz channel or width overwrote the 5 GHz settings
- Nokia: SIM status always "not active"; login used stored instead of typed credentials
- Gateway GPS position was never read
- Admin password now encrypted with the Android Keystore; no third-party crash reporting

## Install
`HINTControl-v1.0.0-pre1-<build>.apk`, signed with the public AOSP test key (v1 + v2 + v3). Android 8.0+. Installs next to the original HINT Control (different package name). Check the download against the `.sha256` file.
