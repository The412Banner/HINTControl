**Hint Plus 1.1.1** shows your gateway's real Wi-Fi and cell options, checked on an Arcadyan TMO-G5AR. Update under **More → Updates**.

## Fixed
- **"No gateway found" on newer Android phones** (reported on a Galaxy S26 Ultra and a Galaxy Z Fold 8 Ultra) when the phone is connected directly to the gateway's Wi-Fi or Ethernet, while it worked through another router. Hint Plus declared Android 17's new local-network permission without ever asking for it; Android's guidance for apps like this is not to declare it, because Android then grants local network access automatically. The declaration is removed. This is the most likely cause; please report if a newer phone still can't find the gateway. Reported on Reddit by Hot-Bat-5813.

## Changed
- **Wi-Fi radios** ([HINT Control #120](https://github.com/zacharee/HINTControl/issues/120)): channel and width pickers only appear when the gateway offers them. On the G5AR each radio only has an on/off switch, and Hint Plus now says so instead of showing "Auto" pickers that did nothing.
- **Cell details**: rows the gateway doesn't report (on the G5AR: bandwidth, ARFCN, PCI, TAC, operator) are left out instead of showing "—".
- **New: Antenna** on Signal → Cell, when the gateway reports it (for example "Internal omni" for the G5AR's built-in antenna).

## Checked on a real gateway
Read-only checks on a TMO-G5AR (firmware 1.00.06): Wi-Fi settings, cell details and the gateway's schedules list. The G5AR has no band-steering setting, so [#133](https://github.com/zacharee/HINTControl/issues/133) doesn't apply to it.

## Install
`HintPlus-v1.1.1-<build>.apk`, signed with the public AOSP test key (v1 + v2 + v3). Android 8.0+. Check the download against the `.sha256` file.
